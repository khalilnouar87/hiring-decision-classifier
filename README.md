# Hiring Decision Classifier

A machine learning pipeline that predicts whether a candidate will be hired based on their education level, skill score, interview score, and personality score. Includes a Streamlit web app for interactive predictions.

---

## Project Structure

```
├── Hiring.ipynb       # Full ML pipeline (EDA, preprocessing, training)
├── app.py             # Streamlit prediction app
├── model.pkl          # Trained Logistic Regression model
├── newdata.csv        # Raw dataset
└── dataset_traté.csv  # Cleaned dataset (generated by notebook)
```

---

## Pipeline Overview

The notebook `Hiring.ipynb` covers:

1. **Exploratory Data Analysis** — distributions, boxplots, and count plots split by hiring decision
2. **Preprocessing** — missing value imputation (mode for categoricals, median for numericals), ordinal encoding, outlier removal via IQR
3. **Model Comparison** — 9 classifiers evaluated with 5-fold cross-validation:
   - SVC (RBF & Polynomial kernels)
   - KNN (k = 5, 11, 113)
   - Logistic Regression
   - Random Forest
   - MLP (Neural Network)
   - Decision Tree
4. **Final Model** — Logistic Regression, saved as `model.pkl`

**Features used:** `EducationLevel`, `SkillScore`, `InterviewScore`, `PersonalityScore`  
**Target:** `HiringDecision` (0 = Rejected, 1 = Accepted)

## Streamlit App

The app lets you input candidate details and get an instant hiring prediction.

### Run locally

```bash
pip install streamlit scikit-learn pandas
streamlit run app.py
```

### Inputs

| Field | Type | Range |
|---|---|---|
| Education Level | Dropdown | Bachelor, License, Master, PhD |
| Personality Score | Slider | 0 – 100 |
| Skill Score | Slider | 0 – 100 |
| Interview Score | Slider | 0 – 100 |

The result is displayed as **Accepted ✅** or **Rejected ❌**.
